# center_scale_repeat

SketchUpで、選択したオブジェクトを「中心基準」で指定した倍率に一発でスケール変更（拡大・縮小）できるプラグインです。

標準のスケールツールで `Ctrl` キー（Macは `Option` キー）を押しながら変形させる操作を、任意の数値で正確に、かつショートカットキーでポンポンと連続実行（リピート）できるように開発しました。

---

## 🚀 特徴

* **中心を自動計算**: 選択したオブジェクト（複数可）の全体の中心点を自動で割り出し、そこを基準に変形します。
* **可変倍率・記憶機能**: 実行時に入力画面が出るため、拡大（例: `1.03`）も縮小（例: `0.97`）も自由自在です。一度入力した数値は記憶されるため、連続実行時は `Enter` を連打するだけでリピートできます。
* **ワンクリックで元戻り**: `Ctrl + Z`（取り消し）を押した際、1回で実行前の状態に戻るよう安全に設計されています。

---

## 🛠 動作確認環境

* Google SketchUp 8 (Ruby 1.8.6 環境)
* Windows / Mac

---

## 📦 インストール方法

1. 本リポジトリの `center_scale_repeat.rb` をダウンロードします。
2. SketchUpの `Plugins` フォルダにファイルを配置します。
   * **Windows**: `C:\Program Files (x86)\Google\Google SketchUp 8\Plugins`
   * **Mac**: `/Library/Application Support/Google SketchUp 8/SketchUp/Plugins`
3. SketchUpを再起動（または起動）します。

---

## ⌨️ おすすめの割り当て設定（ショートカット）

このプラグインは**ショートカットキーに登録することで真価を発揮します。**

1. SketchUpの上部メニューから **「ウィンドウ」 > 「環境設定」** を開きます。
2. 左メニューの **「ショートカット」** を選択します。
3. 検索欄に `Center Scale Repeat` と入力します。
4. 機能一覧から `プラグイン/Center Scale Repeat` を選択します。
5. 「ショートカットを追加」の欄にお好みのキー（例: `Ctrl + Shift + S` や `F4` など）を入力し、**「＋」ボタン** を押して確定します。

---

## 📖 使い方

1. 拡大・縮小したいオブジェクト（グループ、コンポーネント、または線や面の集まり）を選択します。
2. 登録したショートカットキーを押します。
3. ポップアップ画面が表示されるので、倍率を入力して `OK`（または `Enter`）を押します。
   * **拡大したいとき**: `1.03` や `1.1` など、1より大きい数値
   * **縮小したいとき**: `0.97` や `0.9` など、1より小さい数値
4. 連続で同じ倍率で繰り返したい場合は、**「ショートカットキーを押して、そのままEnter」** を繰り返すだけで、中心からポンポンと連続変形します。
